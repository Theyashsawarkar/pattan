#pattan

The ports your dev servers listen on, Docker's published ports, and the tunnels that make them public, in the terminal. Enter opens localhost:port in the browser.

pattan (पत्तन) is Sanskrit for a harbour: where things come in and go out.

#What it shows

  • Dev servers: the TCP ports your own processes listen on from inside a project folder (somewhere under your home, not a hidden folder), so daemons like KDE Connect or mpd stay out. Each with the app (vite, next, nest, astro, django, uvicorn, rails, hugo... read from the command line, then from the project's package.json), the project folder, whether it answers (HTTP status, or tcp for databases, which are never sent HTTP), and how long it has run. Docker's published ports follow, under from docker.
  • The details pane: the page's <title>, the URL, the address other machines on your network can use (when it listens on more than loopback), the process and its command, the folder, the tmux pane it runs in, uptime, memory, CPU, open connections, and its public tunnel URL if it has one.
  • All listening: every listening port on the machine, local or open to the network, with the process when it's yours to see.
  • Tunnels: every tunnel running, with its public URL and the local server it points at:
    • ngrok: from its local API (localhost:4040): the public URL, the request count, and the last requests; R sends one again (handy for webhooks), i opens ngrok's inspector.
    • cloudflared quick tunnels: the trycloudflare.com URL, from its metrics server.
    • tailscale serve / funnel: what this machine serves, and whether it's public (funnel) or tailnet-only.
    • ssh -R forwards: the remote host and port.
    • localtunnel, bore, zrok: found by their process; the URL when their command line gives it.
  • Docker: the ports containers publish.

t on a port starts a tunnel to it with any tool you have installed (ngrok, cloudflared, tailscale funnel, localtunnel, bore). It runs on its own, keeps running after pattan quits, and logs to ~/.local/state/pattan/<tool>-<port>.log.

Everything refreshes every 2 seconds; the HTTP check every 10.

#Install

Needs Linux with ss (iproute2). Docker, tmux and the tunnel tools are optional: pattan uses what's there.

curl -fsSL https://raw.githubusercontent.com/Theyashsawarkar/pattan/main/install.sh | bash

downloads the release binary (or builds it with Go) into ~/.local/share/pattan and links ~/.local/bin/pattan. Or make install (PREFIX, DESTDIR), or go install github.com/Theyashsawarkar/pattan/cmd/pattan@latest.

#As a tmux plugin

set -g @plugin 'Theyashsawarkar/pattan'

prefix P opens pattan in a popup; P inside closes it. Without pattan on your PATH, the plugin builds it with Go the first time.

OptionDefault
@pattan-keyPthe key after the prefix; none binds nothing
@pattan-width / @pattan-height90% / 88%popup size
@pattan-title pattan popup title
@pattan-launcheryour own popup command instead of display-popup; it gets display-popup's arguments (-E -d DIR -T TITLE CMD)

To open it from a status-line click, open a popup that runs ~/.tmux/plugins/pattan/scripts/pattan-run --client '#{client_name}'.

#Command line

pattan                 the screen
pattan list            the dev servers' ports: "5173 vite onads-super/apps/web"
pattan list --all      every listening port
pattan tunnels         the tunnels: "ngrok https://… -> :5173"
pattan --version

#Colours

pattan follows varna's desktop theme (~/.local/state/varna/palette.json, a tools.pattan pick if the theme has one) and changes live with it; without varna it is Catppuccin Mocha. Icons need a Nerd Font; NO_NERD_FONT=1 turns them off.

#Privacy

pattan reads /proc and ss, asks your own ports over localhost, and talks to ngrok's and cloudflared's local APIs. Nothing leaves the machine unless you start a tunnel, which makes that one port public.
